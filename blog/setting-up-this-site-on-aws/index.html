Setting up this site on AWS from scratch

April 3, 2026

A walkthrough of how I took this site from a folder on my laptop to a live deployment on AWS — S3, CloudFront, Route 53, and the mistakes I made along the way.

The first version is intentionally plain: static pages in S3, CloudFront for distribution, Route 53 for DNS, and a small backend path for newsletter work.

The hard part was less about the services and more about the edges between them: cache behavior, certificate timing, deploy confidence, and knowing what changed when something looked off.

That setup now gives me a stable place to ship experiments, write them down, and keep the infrastructure understandable as the site grows.
